# Recipe-catalog

Жобаның мақсаты:
Рецепттерді бір жерде жинап, ыңғайлы реттеу, іздеу және бөлісу мүмкіндігін беретін қосымша жасау. Жоба барысында PHP-мен серверлік бағдарламалау, MySQL-мен жұмыс, пайдаланушыны аутентификациялау және веб-қауіпсіздік негіздері меңгеріледі.

Мақсатты аудитория: үйде тамақ дайындағанды ұнататын адамдар, рецепттерін жинақтағысы келетін пайдаланушылар.

Негізгі мүмкіндіктер:
Мүмкіндік және Сипаттама

Тіркелу және кіру:	Email + құпиясөз, құпиясөз хэштеліп сақталады

Рецепт: CRUD	Қосу, қарау, өңдеу, өшіру (тек өз рецептін)

Санаттар:	Сорпалар, ыстық тағамдар, десерттер, салаттар т.б.

Ингредиенттер:	Әр рецептке бірнеше ингредиент (атауы, мөлшері)

Іздеу:	Атауы немесе ингредиенті бойынша

Сүзу:	Санат, дайындау уақыты, күрделілік деңгейі бойынша

Таңдаулылар:	Ұнаған рецептті сақтап қою

Сурет жүктеу:	Рецепт суреті (түрі мен көлемі тексеріледі)

Рөлдер:	user және admin (санаттарды басқару)

1. Аутентификация және пайдаланушылар

Тіркелу (username, email, құпиясөз)
Жүйеге кіру және шығу
Құпиясөзді хэштеп сақтау
Профильді көру және аты-жөнін, құпиясөзін өзгерту
Рөлдер: user және admin

2. Рецепттермен жұмыс (CRUD)

Create: жаңа рецепт қосу (атауы, сипаттамасы, дайындау қадамдары, уақыты, күрделілігі, санаты, суреті)
Read: рецепттер тізімін қарау және жеке рецепттің толық бетін ашу
Update: өз рецептін өңдеу
Delete: өз рецептін өшіру
«Менің рецепттерім» тізімі

3. Ингредиенттер

Рецептке бірнеше ингредиент қосу (атауы, мөлшері)
Ингредиенттерді өңдеу және өшіру
Рецепт өшкенде ингредиенттерінің де автоматты өшуі (ON DELETE CASCADE)

4. Іздеу және сүзу

Рецепт атауы бойынша іздеу
Ингредиент бойынша іздеу
Санат бойынша сүзу
Дайындау уақыты бойынша сүзу
Күрделілік деңгейі бойынша сүзу
Нәтижелерді беттеу (pagination)

5. Таңдаулылар

Рецептті таңдаулыға қосу және одан алып тастау
Таңдаулылар тізімін қарау

6. Admin функциялары

Санаттарды қосу, өңдеу, өшіру
Кез келген рецептті өңдеу немесе өшіру (қажет болса)

7. Деректерді тексеру (валидация)

Міндетті өрістердің толтырылуын тексеру
Email форматын тексеру
Құпиясөз ұзындығын тексеру (кемінде 8 таңба)
username мен email бірегей екенін тексеру
Уақыт пен ингредиент мөлшері сияқты сан мәндерін тексеру
Сурет түрін (jpg, png, webp) және көлемін (≤ 2 МБ) тексеру

8. Қауіпсіздік

SQL injection-нан қорғау (PDO prepared statements)
XSS-тен қорғау (htmlspecialchars())
CSRF токені (барлық POST формаларында)
Сессия ID-ін кіргеннен кейін жаңарту
Қолжетімділікті тексеру: басқа адамның рецептін өңдеуге немесе өшіруге болмайды
Қорғалған беттерге кірмеген пайдаланушыны login.php бетіне бағыттау
